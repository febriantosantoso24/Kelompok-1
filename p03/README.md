## Program Suhu

Program ini menghitung rata-rata dan suhu tertinggi dari data suhu, lalu menentukan status suhu berdasarkan kategorinya.
Program dapat dijalankan dari folder `p03` dengan perintah berikut:

```bash
python suhu.py
```

bayu mido (33132501002)

`servo.py` digunakan untuk mengontrol pergerakan servo.
`mikrofon.py` digunakan untuk membaca input suara dari mikrofon.
