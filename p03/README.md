Jobsheet 03 - Debugging, Pengujian, dan Dasar OOP Python
Deskripsi

Program ini dibuat untuk mempraktikkan debugging, pengujian menggunakan pytest, dokumentasi program, serta dasar pemrograman berorientasi objek (OOP) menggunakan Python.

Menjalankan Program

Jalankan program suhu dengan perintah:

python suhu.py

Jalankan program servo dengan perintah:

python servo.py
Menjalankan Test

Untuk menjalankan seluruh pengujian:

python -m pytest
